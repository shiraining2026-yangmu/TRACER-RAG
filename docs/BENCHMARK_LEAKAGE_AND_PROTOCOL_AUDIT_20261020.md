# 三模型答案隔离与 Qwen3.5 流程对照审计

检查日期：2026-10-20。范围：远端 adapted_v2 队列中的 Mistral-7B-Instruct-v0.3、Gemma-2-9B-it、Yi-1.5-9B-Chat，以及原 Qwen3.5 两年试卷结果。

检查时 Mistral 正在运行，Gemma、Yi 尚未开始。后两者的判断来自共用驱动和提示词代码审查，不能等同于其实际模型调用已通过审计。

## 结论

1. 在已检查的运行中，未发现将题库标准答案列、答案内容列、解析列或历史 Qwen 答案直接转发给候选模型。
2. 检索与训练数据存在同题重叠，不能声称整个实验完全无数据污染。
3. 候选模型与历史 Qwen3.5 的检索证据、基线提示相同，但完整 v3 链路并不相同，输出预算与失败计分规则也不同。
4. v3 使用评分标签选择错题并保留原先正确题，是依赖标签的条件性修复实验，不能作为全卷盲态部署准确率。

## 直接答案隔离检查

- 两年题目输入共 1,162 条，均未发现标准答案等禁止元数据字段。
- 对题干和选项正文另行扫描“标准答案、正确答案、参考答案、本题答案、答案：A-E”等模式，命中 0 条；作答格式说明单独排除。
- 普通向量 RAG 和 TER 各检查 1,162 条，共 2,324 条；问题与冻结证据逐条一致。
- 两组提示词与原 Qwen3.5 对应生成提示逐条完全一致。
- 将源记录的 answer、initial_answer、critic、reference_answer、score、y_strong 等字段替换为专用测试标记，构造的基线提示不变，标记未进入提示。
- 重建 2,324 条官方模板 token 序列，其 SHA-256 全部匹配 Mistral 服务实际输入日志。
- TER 输入文件虽然来自 Qwen 历史结果文件，但构造提示只读取问题及 retrieved 证据字段；旧 Qwen 初稿、最终答案和批评没有被转发。
- 检查当时已落盘的 224 条候选 v3 输出：初稿和证据均来自该候选的 TER 结果，没有替换为 Qwen 初稿；选中的题均属于该候选 TER 错题。
- v3 的评分 CSV 在推理前用于选择题目，参考答案保留在评分变量中，没有插入 Critic 或回答模型提示。程序使用答案进行路由这一事实仍须公开报告。

## 检索库及 Critic 训练重叠

筛查规则：规范化题干至少 12 字，在检索证据中出现完整题干，且至少 3 个长度不低于 4 字符的选项内容也出现。此规则仅定位明显重叠，不能排除改写或短题干重叠。

普通向量证据中没有命中上述完整题干规则。TER 命中以下 3 道题，共 7 个检索证据块：

| 测试题 ID | 命中的证据 ID |
| --- | --- |
| QB-2021-TCM-01-102 | E-AEK-0012824、E-AEK-0012826、E-AEK-0012825 |
| QB-2022-TCM-03-080 | E-AEK-0026727 |
| QB-2022-TCM-03-103 | E-AEK-0031292、E-AEK-0031291、E-AEK-0031295 |

这些证据的历史问题含对应原题与多个选项，不能等同于仅检索到一般医学知识。
部分历史回答或 K 中也含正确选项内容，但本审计不公开答案键，也不把医学概念重叠本身都判作直接答案泄露。

当前 Critic adapter 的训练清单指向 selective_repair_v2/critic_sft_balanced/critic_sft_train.jsonl。
其中样本 CRITIC-BUILD-00497::balance::0 的历史证据部分包含 QB-2022-TCM-03-080 的完整题干。
它不是训练样本的目标问题，也不是标准答案字段，但属于训练输入与测试题重叠。
重建长度约 1,743 token，低于训练上限 2,560，不会因过长过滤。
训练 JSONL 原始 2,100 条、使用 2,093 条；验证原始 262 条、使用 260 条。
训练及验证用户提示没有发现 reference_answer、reference_status、y_strong 等禁止字段。

## 与历史 Qwen3.5 的流程差异

| 项目 | 历史 Qwen3.5 | adapted_v2 三模型 |
| --- | --- | --- |
| 题目与选项 | 同一版本 | 同一版本 |
| 普通向量证据、R4 Top-3 | 原冻结证据 | 逐题复用相同证据 |
| 普通向量、TER 语义提示 | 原提示 | 检查后完全一致 |
| 解码与量化 | greedy、NF4 4-bit | greedy、NF4 4-bit |
| 回答输出上限 | 32 token | 128 token |
| 格式修复后仍无合法选项 | 默认 A，可碰巧计对 | INVALID，计错 |
| v3 之前的回答批评精修 | 已执行一轮 | 没有该轮 |
| v3 错题筛选起点 | 旧 AlignRAG 最终回答 | TER 直接回答 |
| 保留的正确题 | 旧 AlignRAG 正确题 | TER 正确题 |

历史 Qwen 的实测链路为：R4 -> TER 初稿 -> 回答 Critic -> 旧 AlignRAG 精修 -> 离线选择错题 -> v3 证据 Critic -> 回答生成 -> 与旧 AlignRAG 正确题合并。

当前候选链路为：R4 -> TER 初稿 -> 离线选择错题 -> v3 证据 Critic -> 当前候选回答生成 -> 与 TER 正确题合并。

| 年份 | TER 初稿答对 | 旧 AlignRAG 答对 | v3 筛选错题数 | v3 合并答对 |
| --- | ---: | ---: | ---: | ---: |
| 2021 | 439 | 440 | 114 | 458 |
| 2022 | 473 | 463 | 121 | 489 |
| 合计 | 912 | 903 | 235 | 947 |

原 947/1138 因此不是“从 TER 直接执行当前候选 v3 链路”的实测结果。不可声称两者仅替换了基座模型。

## 其他已确认的限制

此前另行定位的共用病例错位涉及两年各 29 道可评分题，均沿用到当前冻结输入中。
部署预检只证明模板、特殊标记、长度与批量计算等运行属性，不能证明题库质量、无污染或模型医学能力。

正式比较应统一完整推理链、输出与评分协议，修复题库病例和选项边界，清理检索与训练的同题重叠，并使用全部问题进行预先固定的推理比较。
已有结果应保留为带版本与选择条件说明的历史诊断结果。
